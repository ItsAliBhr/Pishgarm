# دفتر اسناد پیشگرم — بسته‌ی آماده برای ساخت با Claude Code

این پوشه همه‌ی چیزی است که Claude Code برای ساختن نرم‌افزار ویندوزی صدور نامه، پیش‌فاکتور، فاکتور و صورت‌وضعیت پیشگرم سازان لازم دارد. همه‌ی محتوا از تحلیل ۴۳۱ فایل آرشیو واقعی به دست آمده است.

## چه چیزهایی داخلش است

| پوشه / فایل | محتوا |
|---|---|
| `CLAUDE.md` | دستورالعمل Claude Code (انگلیسی): فناوری، قواعد، ترتیب خواندن اسناد |
| `docs/01..08` | مشخصات کامل سیستم (فارسی): تحلیل آرشیو، مدل داده، صفحه‌ها، قالب‌ها، قواعد، فناوری و نصب، فازها و آزمون پذیرش |
| `seed/` | اطلاعات پایه‌ی آماده: ۲ سربرگ، ۷ حساب (چک‌سام بررسی‌شده)، ۴۲ شخص و شرکت با مخاطبان، ۲۵ موضوع نامه، ۴۵ بند، ۵۵ قلم کالا و خدمت با آخرین قیمت، واحدها و تنظیمات |
| `templates/` | ۵ قالب Word ساخته‌شده از اسناد واقعی خود شرکت، با جای‌خالی‌های docxtpl، داده‌ی نمونه و PDF پیش‌نمایش |
| `assets/` | مهر شرکت، امضا و تصویر سربرگ |
| `reference/` | ۱۵ نمونه‌ی شاخص از آرشیو و فهرست کامل ۳۶۹ سند (`archive_index.csv`) |
| `tools/` | اسکریپت‌هایی که قالب‌ها را از فایل‌های اصلی ساختند، و یک رندر آزمایشی |

## فناوری انتخاب‌شده (خلاصه)

- **زبان و رابط:** Python 3.12 + PySide6، یک برنامه‌ی دسکتاپ فارسی راست‌به‌چپ.
- **داده:** SQLite، یک فایل روی همان کامپیوتر.
- **خروجی Word:** docxtpl، از روی همین قالب‌ها.
- **خروجی PDF:** از طریق Word نصب‌شده.
- **نصب:** `Setup.exe` با Inno Setup. ویندوز ۱۰ یا ۱۱ لازم است.
- **پشتیبان:** روزانه و خودکار.

جزئیات و دلایل انتخاب در `docs/07`.

## شروع کار با Claude Code

1. این پوشه را در یک مخزن Git بگذارید، مثلاً یک مخزن خصوصی در GitHub. این کار ساخت نسخه‌ی ویندوز با GitHub Actions را ممکن می‌کند.
2. Claude Code را در همین پوشه باز کنید. فایل `CLAUDE.md` خودکار خوانده می‌شود.
3. اولین پیام:
   > اسناد docs را به ترتیب بخوان و فاز ۰ را طبق docs/08 پیاده کن: اسکلت پروژه، بارگذاری seed، پنجره‌ی RTL، تست رندر قالب‌ها، و workflow ساخت ویندوز. در پایان آزمون‌های پذیرش فاز ۰ را اجرا کن.
4. بعد از هر فاز، Setup ساخته‌شده را روی ویندوز امتحان کنید و فاز بعد را بخواهید:
   > فاز ۱ را طبق docs/08 پیاده کن و اسناد طلایی فاز ۱ را به‌عنوان تست بنویس.
5. قبل از فاز ۱، **سؤال‌های باز** انتهای `docs/08` را جواب بدهید، به‌خصوص نسخه‌ی ویندوز و نصب بودن Word روی کامپیوتر پدر.

## نکته‌ها

- **چیزهایی که از آرشیو حذف کردم:** شماره‌حساب‌های اعضای خانواده در فایل «شبا» و کدهای ملی افرادی که فقط در نامه‌های معرفی آمده بودند. داده‌ی پایه فقط حساب‌هایی را دارد که در فاکتورها برای دریافت پول استفاده شده‌اند.
- **کد ملی پدر:** در `seed/issuers.json` هست، چون در فاکتور شخصی ۱۴۰۱ چاپ می‌شد. اگر لازم نیست، پاکش کنید.
- **پیش‌نمایش‌ها:** پیش‌نمایش‌های `templates/previews` با فونت جایگزین ساخته شده‌اند. در Word با B Nazanin خروجی تمیزتر است.

## وضعیت پیاده‌سازی (نسخه‌ی 1.0.0)

فازهای ۰ تا ۳ پیاده شده‌اند:

- **صدور سند در شش گام:** نامه، پیش‌فاکتور، فاکتور، صورت‌وضعیت و لیست اقلام، با هر دو سربرگ شخصی و شرکتی.
- **مبالغ:** ورود به ریال، تومان یا میلیون تومان، با مبلغ به حروف زنده، ارزش افزوده و مارک‌آپ پنهان.
- **بندها:** متغیرهای درون‌خطی، بند آزاد و ترتیب‌دهی با کشیدن. هشدارهای ناسازگاری و خطاهای قفل‌کننده هم دارد، مثل شبای نامعتبر یا جای‌خالی پرنشده.
- **نامه‌ها:** ۲۵ موضوع با فرم فیلد، متن زنده و ویرایش دستی.
- **خروجی:** Word از قالب‌های خود شرکت، و PDF با Word. «PDF کامل» نقشه و لیست اقلام را هم‌اندازه به سند می‌چسباند و می‌تواند ناحیه‌ای را پاک کند.
- **شماره و پوشه:** شماره‌گذاری خودکار و پوشه‌ی «مشتری ← پروژه». نسخه‌ی جدید با پسوند `-v2` ساخته می‌شود و فایل قبلی هرگز بازنویسی نمی‌شود.
- **کار با سندهای صادرشده:** ساخت فاکتور از پیش‌فاکتور، کپی برای مشتری دیگر، و بارگذاری نسخه‌ی نهایی.
- **کارها:** تسک منیجر با کارهای خودکار، صفحه‌ی امروز و شمارنده‌ی کارهای عقب‌افتاده.
- **گزارش:** مطالبات باز، یعنی فاکتورهای پرداخت‌نشده و سپرده‌های آزادنشده.
- **اطلاعات پایه:** همه قابل ویرایش‌اند، با بررسی شبا، شناسه‌ی ملی و کد پستی.
- **پشتیبان:** پشتیبان خودکار روزانه، پشتیبان روی فلش، و بازگردانی.
- **بایگانی قدیمی:** فهرست فایل‌های پوشه‌ی قدیمی زیر هر مشتری، فقط برای باز کردن.

## راهنمای کوتاه استفاده

1. **سند جدید:** در «خانه» روی «+ سند جدید» بزنید و این شش گام را بروید:
   - نوع سند
   - سربرگ
   - مشتری و پروژه
   - محتوا
   - بندها و حساب
   - خروجی

   در گام آخر «ساخت فایل Word» سند را با شماره ثبت می‌کند و Word را باز می‌کند. «ساخت PDF کامل» پیوست‌ها را هم اضافه می‌کند.
2. **مبالغ:** پیش‌فرض ورود «میلیون تومان» است. برای «دونه‌ای ۳۵۰ میلیون» فقط بنویسید `350`. واحد را بالای جدول می‌شود عوض کرد.
3. **ادامه یا تغییر سند:** هر سند نیمه‌کاره خودکار ذخیره می‌شود و از «اسناد» ادامه پیدا می‌کند. برای تغییر سند صادرشده، در صفحه‌ی سند «نسخه‌ی جدید» بزنید.
4. **پیگیری‌ها:** کارهای پیگیری خودکار ساخته می‌شوند. ثبت تاریخ تحویل موقت در صفحه‌ی پروژه، کار «نامه‌ی آزادسازی سپرده» را می‌سازد. وقتی تیک آن را بزنید، ویزارد همان نامه را آماده باز می‌کند.
5. **ظاهر سندها:** ظاهر را فقط در «تنظیمات ← قالب‌های Word» عوض کنید و برچسب‌های `{{ }}` را دست نزنید.

### اجرا برای توسعه

```
pip install -e .[dev]
python -m app
pytest
```

ساخت نصب‌کننده روی ویندوز: `python tools/build_windows.py`. روی GitHub هم هر push یک `PishgarmDocsSetup.exe` می‌سازد و در Release نسخه‌ی `v<version>` می‌گذارد.

سؤال‌های باز `docs/08` به‌صورت تنظیم با همان پیش‌فرض‌ها ذخیره شده‌اند و از صفحه‌ی «تنظیمات» قابل تغییرند.
